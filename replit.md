# Inventaire Flash

## Overview

Inventaire Flash is a rapid ecological pre-diagnostic web tool that allows users to search for a location on an interactive map, define an analysis radius, and query the GBIF (Global Biodiversity Information Facility) API to retrieve species occurrence data. The application displays results as colored zones on the map and provides a summary panel with interpretable text, supporting export to text or image formats.

This is a full-stack TypeScript application with a React frontend and Express backend, designed for environmental impact studies and biodiversity assessments.

## User Preferences

Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture
- **Framework**: React 18 with TypeScript
- **Routing**: Wouter for lightweight client-side routing
- **State Management**: TanStack React Query for server state and data fetching
- **UI Components**: shadcn/ui component library built on Radix UI primitives
- **Styling**: Tailwind CSS v4 with custom CSS variables for theming
- **Mapping**: Leaflet with React-Leaflet wrapper for interactive maps
- **Animations**: Framer Motion for smooth UI transitions
- **Build Tool**: Vite for development and production builds

### Backend Architecture
- **Runtime**: Node.js with Express
- **Language**: TypeScript with ESM modules
- **API Pattern**: RESTful API endpoints registered through a central routes file
- **Static Serving**: Production builds serve static files from dist/public

### Data Layer
- **ORM**: Drizzle ORM with PostgreSQL dialect
- **Schema Location**: shared/schema.ts for shared types between frontend and backend
- **Validation**: Zod with drizzle-zod for schema validation
- **Storage Abstraction**: IStorage interface in server/storage.ts allows swapping implementations (currently MemStorage for development)

### Key Design Patterns
- **Full-screen map layout**: Map occupies 100% viewport with floating UI panels
- **Glass morphism UI**: Semi-transparent panels with backdrop blur effects
- **Alert-based species classification**: Species categorized as high/medium/low priority based on conservation status
- **Confidence scoring**: GBIF data quality assessed using geographic, taxonomic, and temporal factors (6 criteria: geo, tax, time, trace, issues, dedup)
- **Concentric EIE buffer zones**: Three predefined concentric study areas matching environmental impact study standards: Aire immédiate (500m, teal, solid), Aire rapprochée (2km, blue, dashed), Aire éloignée (6km, indigo, dashed). All share the same center; users can enable/disable each zone and customize radii. Analysis merges species across enabled zones with averaged confidence scores.
- **Project type presets**: Standard configurations for common EIE project types (Éolien, PV sol petit/moyen/grand, Urbanisation, Infrastructure linéaire, Carrière/ICPE). Each preset auto-configures the three study area radii and enabled states. Manual adjustments switch to "Personnalisé" mode. Presets defined in `PROJECT_PRESETS` array in `gbif.ts`.
- **About dialog**: Methodology documentation accessible via a "?" button, explaining GBIF API usage, EIE study areas, IUCN classification, and the 6-criteria confidence index.
- **Data export**: CSV (semicolon-delimited with BOM for Excel FR compatibility, formula injection sanitized) and Excel (.xlsx with 3 sheets: Espèces, Métadonnées, Synthèse par groupe). Exports respect active taxon filters. Export module in `client/src/lib/export.ts`.
- **Taxon group filtering**: Species can be filtered by taxonomic group (Oiseaux, Mammifères, Reptiles, Amphibiens, Poissons, Insectes, Arachnides, Mollusques, Plantes, Champignons, Autres). Toggle chips in ResultsPanel with counts; filters apply to both species list and map markers. Select/deselect all supported. `TAXON_GROUPS` and `getTaxonGroupId()` in `gbif.ts`. Occurrences carry `kingdom`, `phylum`, and `class` from GBIF.
- **SINP regional links**: Auto-detects which French region the study area is in using coordinate bounds, and displays relevant SINP (Système d'Information Nature et Paysages) platform links for complementary local data (14 regions covered including overseas territories)

## External Dependencies

### APIs and Services
- **GBIF API**: Primary data source for species occurrence data (api.gbif.org)
- **Nominatim/OpenStreetMap**: Geocoding service for place search functionality

### Database
- **PostgreSQL**: Primary database (configured via DATABASE_URL environment variable)
- **Drizzle ORM**: Database toolkit with migration support via drizzle-kit

### Key NPM Packages
- **Mapping**: leaflet, react-leaflet for interactive maps
- **UI**: Full shadcn/ui component suite (@radix-ui/react-*)
- **Data**: @tanstack/react-query for async state management
- **Export**: html2canvas for map image export functionality
- **Animations**: framer-motion for UI animations

### Development Tools
- **Replit Plugins**: vite-plugin-runtime-error-modal, vite-plugin-cartographer, vite-plugin-dev-banner
- **Build**: esbuild for server bundling, Vite for client bundling
