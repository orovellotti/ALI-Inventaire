---
name: Ali dialogue UX
description: Product rule for how the pre-analysis journey must behave and read in the left panel.
---

The left panel must be an actual step-by-step dialogue: Ali asks one question, the user responds, and Ali acknowledges the response before moving to the next decision.

**Why:** Styling or docking a conventional form inside a chat shell does not satisfy the intended experience. The user explicitly rejected that approach and supplied a conversational script as the reference.

**How to apply:** Preserve the sequence location → perimeter confirmation → study qualification → pre-study explanation → analysis → indicative results. Controls belong directly under the question they answer. Always distinguish known data, potential presence, and field-confirmed presence.
